# SEO audit — FootfallIQ Attendance

Pre-change audit captured on 14 November 2026, before website source changes. Scope approved in [seo-implementation-plan.md](./seo-implementation-plan.md); product facts and business decisions are in [seo-decisions.md](./seo-decisions.md). Implementation status below starts as planned and is reconciled in the final validation report.

## Evidence

- Next.js `14.2.35`, React 18, App Router under `src/app`; no configured trailing slash or host redirects. Node 24 is available; default shell Node 18 is below the project's declared requirement.
- Existing local production output: HTTP 200 homepage, 238,356 bytes of HTML, one H1, eight `data-scene` articles and eight scene-copy blocks, nine phone instances, no JSON-LD. Canonical is `https://footfalliq.in`.
- The live root fetched through the web tool serves Attendance and exposes all eight descriptions. Search results still surface the previous event homepage and `/about` and `/contact`; these are search snapshots, not an exhaustive indexing or backlink inventory.
- Source and Git history inspected: legacy public pages `/about`, `/contact`, `/offerings`, `/team`, `/privacy`, `/terms`. Owner chose Attendance-only scope. No Search Console/backlink export or domain-management credentials have been supplied.
- Public robots, sitemap, and application-login reads were unavailable through the web tool; source inspection establishes their local behavior. Production HTTP behavior and authenticated-app security are not established by that tool failure.

## Documentation used

Use the installed Next.js 14 APIs while consulting current search guidance: [Next.js 14 Metadata API](https://nextjs.org/docs/14/app/api-reference/functions/generate-metadata), [metadata robots route](https://nextjs.org/docs/14/app/api-reference/file-conventions/metadata/robots), [Google JavaScript SEO](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics), [sitemaps](https://developers.google.com/search/docs/crawling-indexing/sitemaps/build-sitemap), [Organization](https://developers.google.com/search/docs/appearance/structured-data/organization), [software-app rich results](https://developers.google.com/search/docs/appearance/structured-data/software-app), and [Schema.org WebApplication](https://schema.org/WebApplication). Valid descriptive schema does not establish eligibility for a Google software-app rich result when real offers/reviews are absent.
